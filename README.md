# Student Study Recommendation Agent

## SLE-1 – Basic AI Agent Project

### About the Project

This project is a simple rule-based AI agent developed using Python.

The agent takes a student's study situation as input and gives a suitable study recommendation based on predefined rules.

### How the Agent Works

The agent follows these steps:

1. It shows different study situations.
2. The student selects a situation.
3. The agent checks the corresponding rule.
4. The agent gives a recommendation.

### Rules Used

- If the exam is tomorrow → Focus on revision and important topics.
- If the exam is next week → Make a study plan and study regularly.
- If the student is tired → Take a short break and then continue studying.
- If the student does not understand a topic → Review the basics and ask the teacher for help.

### Technology Used

- Python

### How to Run

1. Install Python.
2. Open `agent.py` in VS Code or another Python editor.
3. Run the program.
4. Enter a number from 1 to 4 when asked.

### Example

**Input:** 1

**Output:** Focus on revision and important topics.
